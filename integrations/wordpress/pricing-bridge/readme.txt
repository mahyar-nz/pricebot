=== رابط پایش قیمت فروشگاه ===
Requires at least: 6.5
Requires PHP: 8.1
Requires Plugins: woocommerce
Stable tag: 0.1.0
License: GPL-2.0-or-later

نسخه آزمایشی برای اتصال فقط‌خواندنی کاتالوگ ووکامرس به سامانه.
این افزونه ترب یا ترب‌پی نیست و داده رقبا دریافت نمی‌کند.

== Installation ==
ابتدا روی فروشگاه آزمایشی نصب شود. ووکامرس و HTTPS باید فعال باشند.
پس از فعال‌سازی: ووکامرس ← رابط پایش قیمت ← ساخت کلید فقط‌خواندنی.
در سامانه: فروشگاه‌ها ← افزودن ووکامرس ← افزونه رابط.
نشانی فروشگاه، واحد واقعی قیمت و کلید را در فرم امن وارد کنید؛ سپس آزمایش و همگام‌سازی.
کلید فقط یک‌بار نمایش داده می‌شود و در وردپرس به صورت SHA-256 ذخیره می‌شود.
تعویض کلید، لغو اتصال یا غیرفعال‌سازی افزونه دسترسی قبلی را باطل می‌کند.

== Scope ==
فقط خواندن محصولات ساده و متغیر منتشرشده و تنوع‌های منتشرشده.
بدون مسیر تغییر قیمت، خواندن سفارش و مشتری، ارسال پیامک یا پرداخت.
نصب به‌تنهایی هیچ داده‌ای به خارج ارسال نمی‌کند. سامانه با کلید و HTTPS داده را می‌خواند.
کلید در سربرگ X-Pricing-Token ارسال می‌شود؛ آن را در لاگ وب‌سرور ثبت نکنید.
همگام‌سازی فعلاً کامل است؛ webhook و همگام‌سازی حذف‌ها در نسخه بعدی لازم‌اند.
محصول گروهی، خارجی، محافظت‌شده با رمز، شبکه multisite و چندواحدی پشتیبانی نمی‌شوند.
کاتالوگ حاوی محصول محافظت‌شده برای بازبینی دستی متوقف می‌شود.

== Validation ==
آزمون PHP با محیط شبیه‌سازی‌شده و قرارداد اتصال سامانه وجود دارد.
این بسته هنوز روی WordPress/WooCommerce واقعی staging نصب و آزموده نشده است.
برای عرضه عمومی، آزمون staging، سازگاری نسخه‌ها و بررسی مستقل امنیت ضروری است.
