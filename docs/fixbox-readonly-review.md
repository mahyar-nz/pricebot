# بررسی فقط‌خواندنی FixBoxIran — ۱۵ نوامبر ۲۰۲۶

دامنه مجاز کار: اتصال و بررسی فروشگاه با اجازه کاربر؛ تغییر قیمت صریحاً ممنوع. هیچ قیمت، موجودی یا تنظیم فروشگاه تغییر نکرد. افزونه جدید روی فروشگاه نصب نشد و هیچ کلید تازه‌ای در سایت ساخته نشد. مشخصات ورود در کد، گزارش یا تنظیمات پروژه ذخیره نشده‌اند.

## شواهد زنده

- ورود به پیشخوان موفق بود. افزونه رسمی ترب `products-extractor-for-woocommerce` نسخه 2.4.0 فعال بود. افزونه ترب‌پی جداست و برای پرداخت اقساطی است؛ به آن دست زده نشد.
- ابزار موجود «بررسی ارتباط با ترب» اجرا شد؛ هر دو مقصد `extractor.torob.com` و `api.torob.com` سالم گزارش شدند. این نتیجه فقط تشخیص ارتباط خروجی افزونه را تأیید می‌کند.
- وبهوک محصولات فعال و صف ارسال در لحظه بررسی صفر بود. این مشاهده، زمان تأخیر و پوشش همه محصولات در ترب را تضمین نمی‌کند.
- واحد واقعی ووکامرس `IRT` (تومان)، تعداد اعشار صفر. این مقدار از تنظیمات خوانده شد؛ ذخیره تنظیمات انجام نشد.
- صفحه پیش‌نمایش ترب فقط ۱۰ محصول آخر را نشان می‌دهد و طبق توضیح خود صفحه داده ارسال نمی‌کند. JSON ارسالی کاربر نمونه همین صفحه است.
- Store API عمومی ووکامرس با یک درخواست GET برای همان ۱۰ شناسه پاسخ ۲۰۰ داد. هیچ رمز یا کلید مدیریتی در این درخواست استفاده نشد. [مستندات رسمی Store API](https://developer.woocommerce.com/docs/apis/store-api/resources-endpoints/products/)

## نتیجه تطبیق نمونه

| نتیجه | تعداد |

| تطابق قیمت و موجودی محصول ساده | ۸ |
| محصول متغیر، نیازمند تفکیک تنوع‌ها | ۲ |
| شناسه گمشده | ۰ |
| اختلاف در محصولات ساده | ۰ |
| درخواست تغییر قیمت | ۰ |

محصول 956، «والولین ادونس 5w30»: پیش‌نمایش ترب ۸٬۵۰۰٬۰۰۰ تومان؛ Store API قیمت شروع ۲٬۱۰۰٬۰۰۰ و بازه ۲٬۱۰۰٬۰۰۰ تا ۸٬۵۰۰٬۰۰۰ تومان دارد. این اختلاف الزاماً خطای قیمت نیست؛ محصول مادر چند حجم را جمع می‌کند. محصول 962 نیز متغیر است، حتی با یک قیمت نمایشی. هر دو باید با شناسه تنوع و حجم دقیق بررسی شوند و نباید قیمت مادر به فرزندها تعمیم یابد.

گزارش ماشین‌خوان در `evidence/fixbox-catalog-audit.json` قرار دارد. تصویر پنل مدیریت فروشگاه به‌صورت محلی نگه‌داری می‌شود. نمونه دریافت‌شده اطلاعات رقبا نیست و پوشش کامل کاتالوگ را اثبات نمی‌کند.

ابزار تکرارپذیر `scripts/audit-store-sample.mjs` فقط GET دارد، مقصد HTTPS را با DNS عمومی و اتصال ثابت بررسی می‌کند، redirect را نمی‌پذیرد و گزارش را بدون بازنویسی فایل قبلی ذخیره می‌کند. واحد پیش‌نمایش باید صریحاً از تنظیم فروشگاه تعیین شود.

## رابط اختصاصی مشتری

بسته `apps/web/public/downloads/pricing-bridge-0.1.0.zip` ساخته شد و روش «افزونه رابط» در فرم اتصال سامانه اضافه شد. نسخه اول فقط محصولات منتشرشده ساده/متغیر و تنوع‌هایشان را می‌خواند. API اختصاصی GET دارد؛ کلید مخصوص این مسیرهاست و به سفارش، مشتری، پرداخت یا حساب مدیریت دسترسی نمی‌دهد. هش کلید در وردپرس و خود کلید به صورت رمزنگاری‌شده در سرور سامانه ذخیره می‌شود. لغو، تعویض و غیرفعال‌سازی کلید را باطل می‌کند.

این افزونه کد مستقل پروژه است، کد نمونه raghibot در آن کپی نشده است. تست‌های PHP شبیه‌سازی‌شده‌اند؛ نصب و آزمون واقعی WordPress/WooCommerce staging هنوز انجام نشده است. همگام‌سازی فعلاً کامل و دستی است؛ وبهوک، حذف محصولات، اتصال خودکار و انتشار عمومی افزونه باقی مانده‌اند. روی فروشگاه اصلی تا پایان آزمون staging نصب نشده است.

اتصال‌های جدید در فرم فقط‌خواندنی ثبت می‌شوند. API تغییر حالت خودکار و آداپتور ارسال قیمت را برای این حالت رد می‌کنند. اتصال‌های قدیمی فاقد مقدار صریح مجوز نیز فقط‌خواندنی تلقی می‌شوند.

## چیزی که هنوز تأیید نشده

ورود به وردپرس و سلامت افزونه ترب به معنی داشتن توکن Shop API یا دسترسی داده رقبا نیست. دریافت کامل پیشنهادهای رقبا، تازگی، مجوز استفاده و پوشش نمونه‌های واقعی همچنان برای عرضه تجاری لازم‌اند. Shop API فعلی پروژه فقط محصولات خود فروشگاه را می‌خواند. [مستندات رسمی ترب](https://github.com/torob/Torob-Sync/blob/main/shop_api.md)
