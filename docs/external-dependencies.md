# اتصال‌ها و نیازهای خارجی

| اتصال | وضعیت واقعی | نیاز |
|---|---|---|
| WooCommerce REST v3 | آداپتور و مسیر اتصال/همگام‌سازی/تغییر قیمت نوشته شده؛ آزمون زنده نشده | فروشگاه staging، کلید کم‌دسترسی مجاز، واحد پول روشن، تست variation و sale |
| ملی‌پیامک | آداپتور الگویی مبتنی بر منبع رسمی؛ ارسال زنده آزمون نشده | حساب، رمز API و bodyId الگوی تأییدشده در محیط امن |
| ترب، ایمالز، اسنپ‌شاپ، تپسی‌شاپ، دیجی‌کالا | registry و وضعیت غیرفعال؛ داده دستی مجاز | مستندات و دسترسی تجاری مجاز |
| باسلام | مرز OAuth/قابلیت‌ها؛ تأیید عملی نشده | اپلیکیشن مجاز، redirect و scopes مستند |
| پرداخت | غیرفعال | انتخاب درگاه، مستندات sandbox و callback معتبر |
| SMTP | گردش‌کار کامل هنوز پیاده نشده | سرویس ارسال و تکمیل verify/reset |
| Redis | worker نوشته و کامپایل شده؛ اتصال واقعی این میزبان آزمون نشده | Redis مستقل یا Docker |

متغیرهای پایه در `.env.example`: DATABASE_URL، WEB_ORIGIN، SESSION_SECRET، ENCRYPTION_KEY، API_PORT، REDIS_URL و SMS_PROVIDER. نام دقیق متغیرهای ملی‌پیامک را با `apps/api/src/auth.ts` و آداپتور تطبیق دهید. هیچ کلید یا شناسه‌ای از روی حدس معتبر تلقی نمی‌شود.

کد و فرمت درگاه: [کتابخانه رسمی ملی‌پیامک](https://github.com/Melipayamak/melipayamak-node). صفحهٔ ارائه‌شدهٔ کاربر و منبع رسمی برای مطالعه استفاده شده‌اند؛ موفقیت شبکهٔ production ادعا نشده است.
