# معماری فعلی

مونوریپو pnpm/Turborepo: Next.js App Router در `apps/web`، REST NestJS در `apps/api`، PostgreSQL با Prisma 7 و یک بستهٔ محاسباتی بدون وابستگی به UI در `packages/core`.

مرورگر از rewrite هم‌مبدأ `/api/v1` استفاده می‌کند. نشست opaque در کوکی HttpOnly است؛ سرور hash توکن را ذخیره می‌کند. هر درخواست سازمانی عضویت را بررسی می‌کند. اسرار WooCommerce با AES-256-GCM رمز می‌شوند. فروشنده و مشاهدهٔ بازار دو مرز مستقل هستند.

قیمت‌ها رشته‌های decimal با واحد IRR یا IRT هستند. پیشنهاد، تأیید و اجرا رکوردهای مستقل‌اند. دادهٔ دستی provenance دارد و به معنی دریافت کامل بازار نیست. نبود شواهد پوشش کامل مانع اجرای راهبردهای متکی به بازار می‌شود.

Worker فعلی فقط نگهداری رکوردهای امنیتی را انجام می‌دهد؛ زمان‌بندی گستردهٔ بازار و اجرای قیمت هنوز تکمیل نشده است. برای جلوگیری از میکروسرویس غیرضروری، matching فعلاً در TypeScript است؛ سرویس Python فقط با نیاز عملی افزوده خواهد شد.

مرزهای ناقص دامنه: تفکیک کامل canonical catalog/listing/variant، RLS، versioned billing و orchestration صف هنوز در نقشهٔ راه‌اند. جداسازی موجود مبتنی بر membership و شرط tenant در query است؛ ادعای RLS فعال نداریم.
