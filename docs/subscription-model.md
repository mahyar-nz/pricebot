# اشتراک

نسخهٔ فعلی trial، quota محصول/فروشگاه، تنظیمات تعرفه و quote دارد. mutation حساس به اشتراک فعال نیاز دارد. quota محصول در تراکنش با قفل سازمان کنترل می‌شود.

پرداخت غیرفعال است. نسخه‌بندی کامل plan، addon، coupon، تمدید/تغییر پلن، settlement معتبر و usage idempotent هنوز تکمیل نشده‌اند. raw request با product-market check یکسان فرض نشود. قیمت seed تعرفهٔ تجاری تأییدشده نیست.
