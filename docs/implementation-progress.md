# وضعیت واقعی — ۱۵ نوامبر ۲۰۲۶

نسخه قابل اجرا و در حال آزمون است؛ آماده فروش عمومی با همه امکانات نیست. گزارش مرجع: release-readiness.md.

۹۹ آزمون core، ۱۴ API، ۱ worker، ۲۱ سناریوی HTTP و ۶ OTP موفق: جمع ۱۴۱ سناریوی مستقل SaaS. ۱۳ بررسی امنیتی افزونه PHP جداست و با stub اجرا شده؛ با نصب WordPress واقعی برابر نیست. تست‌های نمونه قدیمی raghibot در این اعداد نیستند.

افزونه اختصاصی آزمایشی فقط‌خواندنی، دانلود در داشبورد، کلید محدود به کاتالوگ، خواندن تنوع‌ها و منع تغییر قیمت در API/آداپتور اضافه شدند. کد نمونه خارجی کپی نشده است. هنوز webhook، حذف‌ها و آزمون نصب staging لازم‌اند.

فروشگاه FixBoxIran با اجازه کاربر بررسی شد: افزونه رسمی ترب فعال، diagnostic دو مقصد سالم، واحد تومان. در نمونه زنده ۱۰ محصول، ۸ تطابق ساده و ۲ محصول متغیر ثبت شد. هیچ قیمت یا موجودی تغییر نکرد؛ هیچ افزونه یا کلید جدیدی روی سایت اصلی نصب/ساخته نشد. این تست، دسترسی قیمت رقبا یا اتصال Shop API را تأیید نمی‌کند.

ساخت وب و API و core، lint، PostgreSQL واقعی و آزمون‌های HTTP/OTP تأیید شدند. بخشی از رابط ورود/تعرفه/اتصال‌ها در مرورگر بررسی شد. Docker، Redis واقعی، CI، load/restore، درگاه پرداخت و پیامک زنده همچنان بررسی نشده‌اند. صف خودکار قیمت، billing کامل، بازیابی حساب/MFA و مجوز داده رقبا موانع اصلی عرضه‌اند.
