# کار بعدی

این پروژه بازنویسی نشود. نسخه فعلی و داده‌ها حفظ شوند؛ گزارش نهایی بررسی در release-readiness.md و پیشنهاد سرور در server-sizing.md است.

## اولویت اصلی: امکان عرضه واقعی با محور ترب

دسترسی WordPress فروشگاه FixBoxIran برای بررسی فقط‌خواندنی ارائه و بررسی شد؛ هیچ تغییر قیمت مجاز نیست. هنوز توکن Shop API یا منبع مجاز داده رقبا نداریم. Shop API فعلی فقط کاتالوگ خود فروشگاه را می‌خواند. بدون منبع رقبا، فروش قابلیت «پایش خودکار ترب» قابل تأیید نیست. کارهای داخلی زیر قابل ادامه‌اند.

1. صف چندسازمانی قیمت و پایش، سهمیه و زمان‌بندی، ثبت snapshot قابل ممیزی، retry/reconciliation و rollback کنترل‌شده؛ با سرویس محلی شبیه‌سازی‌شده و تست crash/race.
2. چرخه کامل plan/version/invoice/payment و تمدید/لغو، مصرف idempotent و callback تکراری؛ sandbox درگاه پیش از پول واقعی.
3. verify/reset ایمیل، MFA مدیر، دعوت اعضا و بازیابی حساب.
4. catalog canonical/variant/listing، صف بازبینی تطبیق و CSV استاندارد با پیش‌نمایش و تشخیص واحد پول.
5. تقدم قوانین سازمان/فروشگاه/بازار/دسته، RLS/قیدهای بین‌سازمانی، سیاست نگهداری و حذف داده.
6. اجرای CI اضافه‌شده و Compose روی Linux staging؛ PostgreSQL 18.7 یا patch پشتیبانی‌شده جدیدتر، Redis واقعی، backup/restore و تست بار.
7. مرورگر صفحات داخلی و فرم‌های هر نقش، keyboard/focus و دسترس‌پذیری، سپس آزمون زنده فروشگاه staging و پیامک الگویی با دسترسی مجاز.
8. افزونه `integrations/wordpress/pricing-bridge`: نصب روی staging واقعی و آزمون محصولات ساده/متغیر، فعال‌سازی/لغو، افزونه‌های امنیتی و proxy؛ سپس webhook امضاشده، حذف‌ها و جریان اتصال آسان. نسخه 0.1.0 فقط‌خواندنی است و روی سایت اصلی نصب نشده.

انجام‌شده: ۹۹ آزمون core، ۱۴ API، ۱ worker، ۲۱ سناریوی HTTP، ۶ OTP و ۱۳ بررسی PHP مجزا؛ تشخیص زنده ارتباط افزونه ترب، تطبیق نمونه عمومی فروشگاه، بسته رابط مشتری و کنترل فقط‌خواندنی. این‌ها جایگزین موارد باز بالا نیستند.
